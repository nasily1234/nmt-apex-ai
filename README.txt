NMT APEX AI Android Studio project (prototype 0.1)
Open this folder in Android Studio with Android SDK 35 installed, allow Gradle sync, then Build > Build APK(s).
This environment did not have Android SDK/Gradle installed, so no APK binary is included.
The app uses a local WebView asset; screenshot preview and risk calculator work locally.
It does NOT contain an AI vision backend and does NOT connect to Deriv or place trades.
Verify broker tick size/value and all calculations on demo before relying on them.
